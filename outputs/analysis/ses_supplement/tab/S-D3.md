# 評価設計

「訓練期間3年」は本文の記述。実装では 3–6m 以降の horizon で train_start を前倒しし、学習ステップ数を 33 に揃えている（scripts/variant/run_ses_b3_ablation_queue.sh:17-23 に明記）。

| 項目      | 設定                                                   |
|:--------|:-----------------------------------------------------|
| 予測時点 t0 | 2023-01-01                                           |
| 訓練期間    | 3年（実装では horizon ごとに学習窓を33ステップへ等化）                    |
| 評価期間    | 1年を3か月ずつ4分割（W1:1–3m / W2:4–6m / W3:7–9m / W4:10–12m） |
| リーク防止   | train_end = t0 − 12か月。ラベル判定のみ後方に許す                   |
| 評価指標    | AUC-ROC（bootstrap による95%信頼区間つき）                      |
| 予測単位    | 開発者 × ディレクトリのペア                                      |

出所: scripts/variant/run_ses_b3_ablation_queue.sh:15-37 ／ SES/ses_main.tex
