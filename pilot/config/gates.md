**追記(正式Loop7、層あたり10件以上に拡大)**: GitHub Search APIで候補母集団を拡大し、31リポジトリを追加投入(node.jsはGitHub側のGraphQL内部エラーが解消せず技術的制約により除外)。**既存2+第1弾6+追加31=計39リポジトリ**で主解析モデルを再実行。
