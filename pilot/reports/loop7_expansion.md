# Loop 7 — 拡大

実施日: 2026-09-13
きっかけ: Loop8で主解析モデルを2リポジトリ(home-assistant/core, grafana/grafana)で試運転したところ、Aの係数が有意に負(H1b支持)という結果が出た。これが2リポジトリだけの偶然でないか確認するため着手。

## やったこと

1. **候補探索**(`scripts/pilot/loop7_discover_repos.py`): GitHub Search APIで `stars:>2000 pushed:>2026-08-01 created:<2024-01-01` の人気リポジトリ1000件を取得
2. **CODEOWNERS保有確認**: 1000件中271件がCODEOWNERSファイルを保有
3. **エントリ数フィルタ**(`scripts/pilot/loop7_filter_codeowners.py`): 非コメント・非空行エントリ数≥50のもの32件に絞る(Loop0の教訓: 存在確認だけだとmicrosoft/vscodeのような薄いCODEOWNERSが混ざる)
4. **A軽量推定**(`scripts/pilot/loop7_estimate_A.py`): 直近PR100件のサンプルで「agent(login or trailer)によるPRの割合」を代理指標として算出
5. **2023-01以前作成の25件に絞り、高・中・低3層から2件ずつ抽出**
