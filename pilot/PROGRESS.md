## phase2(2026-09-21) — 主要な結論を3つ訂正した

「トップ国際学会に通る水準まで自律的に検証を進める」という指示を受けて実施。
作業は `pilot/phase2/` に閉じている(スクリプト12本、出力、図、レポート)。**詳細は `pilot/phase2/reports/FINDINGS.md`。**

### ★phase1 の結論のうち3つが誤りだったと判明

| phase1 の結論 | phase2 の検証結果 |
|---|---|
| H1b「評価工程からも人間が退く」(係数 -0.053, p=0.0025) | **誤り。** 比率低下は 100% 分母の膨張(dilution)。人間のレビュー量はむしろ増えている |
| RQ3「AI関与度が高いと承認が +3.52日 遅れる」(p=0.0003) | **撤回。** イベントスタディでは全 k で非有意。選択効果だった |
| H2b'「参入障壁が下がり新規参入が小タスク化」(4推定中3で有意) | **撤回。** イベントスタディでは再現しない |

### やったこと

- **D1 分解**: `H_E = 人間の評価件数 / (人間+AIの評価件数)` を分子・分母に分けて推定。
  人間の評価件数 +0.049(p_repo=0.395、非有意)、AI の評価件数 **+0.265(p_repo=0.0017)**。
  人間レビュアー人数も非有意(-0.014)。**減っている人間側の指標は一つもない**。
  集計値でも人間の評価件数は 28,126(2025-09) → 46,072(2026-08) と増加、AI は 2,034 → 10,860(5.3倍)
- **D2/D3/D4 因果識別**: モジュール単位の「AI初参入月」を処置にする設計(D3)は、処置時点が定義上
  「活動が活発な月」に選ばれるため k=0 で全アウトカムが跳ね上がり失敗(log人間評価件数 +1.31)。
  **処置をリポジトリ単位(管理者による AI レビューボット導入)に上げて解決(D4)**。treated 7件、never-treated 24件。
  導入後: AI の評価件数 +0.313(p=0.00015)、H_E **-0.152(p=1.3e-11)**、一方で
  **人間の評価件数 +0.088(p=0.157)、人数 +0.061(p=0.130)、PRあたり人間レビュー +0.051(p=0.831) と全て非有意**。pre-trend もほぼフラット
- **D6 頑健性**: 閾値12通りすべてで符号・有意性が一致。stacked DiD でも同じ(AI +0.205 p=0.0038 / 人間 +0.055 p=0.280)。
  **randomization inference(偽処置300回)で AI 側 p=0.0000、H_E p=0.0000 に対し、人間側は p=0.410 で偽処置と区別がつかない**
- **D9 同値性検定**: null result の裏付け。**評価工程の人間側指標すべてで「10%以上の減少はない」と片側検定で言える**
  (人間の評価件数 p=0.0013、人数 p=0.0000、PRあたり p=0.0105、活動人数 p=0.0007、新規参入 p=0.0004)。
  ただし40件中13件は「不確定(検出力不足)」で、承認までの日数などは MDE が 3.9〜9.9日と大きい
- **D7 負担**: 人間が承認前に読む AI コメントは **+0.334(p=0.00034)** と約33%増。PR 規模を統制しても不変。
  しかし承認までの日数・マージまでの日数・承認率・マージ率はいずれも非有意
- **D10/D11 ★メカニズム**: GitHub のレビュー state を見たところ、
  **AI レビューの 99.6% が COMMENTED。APPROVED は 0.4%、CHANGES_REQUESTED は 78,529件中わずか6件。**
  人間は APPROVED 39.1% / CHANGES_REQUESTED 3.3% / COMMENTED 57.6%。
  エージェント別でも copilot-pull-request-reviewer 0.1%、cursor 0.0%、claude のみ 12.1%(全体 0.30%)。
  **対照的に legacy_bot(CI ボット等)の判断率は 43.6%。決定論的な自動化には判断権限があるのに、LLM には与えられていない**
- **D12 図**: `pilot/phase2/figures/` に3点(dilution の推移、イベントスタディ、レビュー種別)

### 論文としての主張

**「AI は『発言者』として追加されたが、『判断者』としては参加していない。だから人間は減らない。」**
比率(share)指標は異質な行為を同じ単位で数えるため「人間の後退」を過大に読ませる、という測定上の貢献と、
リポジトリ単位の準実験による因果識別、そして制度的メカニズムの特定をあわせて主張する。

### 追加検証(D13〜D18、同日)

- **D14 用量反応**: 導入後の AI レビュー比率を連続処置にすると log(人間の評価件数) は **+0.407(p=0.226)** でむしろ正。
  高用量4リポジトリに絞っても非有意。**AI を大量に入れても代替は起きない**。null result の最重要の頑健性チェック
- **D15 分配**: レビュー負荷は元々強く集中(上位10%のレビュアーが全レビューの **73.5%**、Gini 0.236)。
  AI 導入で集中度もコア/周辺別のレビュー量も変化しない。**分配も不変**
- **D13 AI コメントは無視されていない**: レビュー592,950件をレビュー単位で分析。state を揃えた比較(COMMENTED 同士)で
  後続7日以内のコード変更率は **人間 60.6% / AI 60.7%** とほぼ同一。PR 固定効果を入れた同一 PR 内比較でも非有意(p=0.686)。
  一方 **人間の APPROVED 後は 26.1%** しか続かない → 「判断は PR を終わらせるが、コメントは終わらせない」
- **D18 配置**: 全203,663 PR の被覆は 人間のみ60.1% / 人間+AI 16.7% / AIのみ1.3% / **レビュー0件21.9%**。
  **AI レビューが付いた PR の 92.8% は人間も既にレビューしている**(=冗長な重ね掛け)。
  ただし導入後に**レビュー0件の PR が -5.8pt(p=0.024)**、AI のみの PR が +3.3〜5.0pt。**レビュー空白を一部埋める便益はある**
- **D16/D17 生成工程**: D16 単独では「生成側で人間が減る」(k=+3 で -0.091, p=0.064)ように見えたが、
  **D17 の直接検定(module×month×stage の縦持ちで post×is_G を推定)で非対称性は確認できず**
  (生成側イベントで差 +0.011, p=0.637)。生成側で減って見えたのは同じイベントで評価側も同程度に減っていたためで、
  **工程間の差ではなかった**。一度「決定的な非対称性」と判断したが撤回した

### 残る限界(→ 下の「全期間版」でほぼ解消した)
